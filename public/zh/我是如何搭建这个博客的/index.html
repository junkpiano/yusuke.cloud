我是如何搭建这个博客的

2021年6月30日 · Yusuke Ohashi | 语言:
  • 🇺🇸
  • 🇩🇪
  • 🇯🇵

这是 2021 年 6 月时的一份快照。我来写写这个博客。 下图展示了我的博客架构。

核心#

  • Linode
  • Dokku

这个博客运行在 Linode 的 VPS 上。博客跑在一个 Docker 容器里,我用 Dokku 来管理容器(应用)。Dokku 是一个基于脚本的 PaaS,也是开源软件。作为 Heroku 的替代品,它兼容 Heroku 的 buildpack。令人欣慰的是,只需推送代码,就能在 Dokku 上运行任何应用。

费用:每月 $10

CI/CD#

  • Github Actions

文章一写完,我就会把它推送到 GitHub。 部署交给 GitHub Actions 处理。在用 GitHub Actions 之前,我用过被 Oracle 收购前的 Wercker 和 Travis CI,当然还短暂用过一阵 Circle CI。

费用:免费

资源管理#

  • S3
  • CloudFront

我把图片存放在 AWS S3(Simple Storage Server)中,并通过 AWS CloudFront 分发。 我在考虑要不要单独写一篇文章介绍这部分。如果你熟悉 AWS,一眼就能明白一切;但如果你像当年的我一样毫无经验,寥寥几句是讲不清楚的。

费用:每月 $0.01(取决于这个网站有多受欢迎)

DNS#

  • Cloudflare
  • Namecheap

我用 Cloudflare 作为 DNS 服务器,域名托管在 Namecheap。

费用:免费(域名除外)

监控#

  • Google Analytics

不用说,我也在统计你哦。

费用:免费

联系方式#

  • Fastmail
  • Twitter

我以前搭建过好几个邮件服务器,但事实证明,搭得不好的邮件服务器非常脆弱。 我用 Fastmail 作为 Gmail 的替代品。Fastmail 是付费服务,所以没有广告。在 Gmail 那里我是产品,而在 Fastmail 这里我是客户。

话虽如此,你可以给我发邮件,但更推荐用 Twitter 私信联系我。@junkpiano

费用:每年 $35

未来#

我正在开发自己的 CMS(内容管理系统)。第一个目标是整理图片、PDF 等资源。文本编辑的工作量巨大,我暂时不打算自己实现。文章我会继续用 VSCode 来写。

我的博客目前是静态网站,但将来也许会变成动态网站。说不准。只要我不放弃,这里总会发生点什么。

费用:N/A

总结#

我介绍了如何以很低的开销搭建自己的博客。如果你还没有自己的博客,我鼓励你搭建一个。它会是你很好的作品集。
